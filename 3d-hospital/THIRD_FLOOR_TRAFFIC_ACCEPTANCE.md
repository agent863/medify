# 三樓交通驗收矩陣

> 基準版本：v345  
> 用途：作為三樓病患、護理師、醫療車與給藥機器人的回歸驗收基準。  
> 本文件先固定「應該發生什麼事」，不代表目前所有情境都已通過，也不會在本階段發布網站。

## 一、全域不可違反規則

| 編號 | 驗收規則 | 失敗判定 |
| --- | --- | --- |
| G-01 | 固定幾何優先：人物與機器人不可穿越病房牆、玻璃、護理站櫃檯、花圃或非門洞區域。 | 任一角色進入牆、玻璃、櫃檯或花圃，或因避讓而改走穿牆路線。 |
| G-02 | 公共走廊採固定靠右線。對向雙方若位於不同車道且路徑不交疊，不應互相停等。 | 角色被拉回走廊中央、斜切病房門、或在距離尚遠時停下。 |
| G-03 | 病患保留原路徑與速度優先權；護理師／醫療車採柔性跟隨，不以硬碰撞把病患封鎖。 | 病患被護理師拖慢、改向，或兩者融合後才在門口停下。 |
| G-04 | 正常短暫重疊只允許作為脫困過渡；脫困後應恢復前後順序，不得持續疊在一起行走。 | 角色長時間重疊、左右閃動、原地旋轉或互相推回。 |
| G-05 | 有意義的等待必須綁定明確對象與原因；不能因一名角色的等待，讓遠處無關病患、護理師或機器人一起停止。 | 非衝突角色同步停住，或原等待對象離開後仍持續等待。 |
| G-06 | 行走角色連續 1.2 秒沒有實際位移時，重新賦予目前任務；但明確的門側等待、機器人安全點等待與柔性跟隨停步屬於刻意等待，不得誤重派。 | 失效任務永久停住，或刻意等待被重派後產生來回抖動。 |
| G-07 | 角色等待或減速時維持當下朝向；只有路徑確定改變時才轉向。 | 停等時左右亂閃、原地轉圈、轉身穿牆或腳步持續抖動。 |

## 二、固定距離與時間基準

以下數值是驗收帶，不要求每一幀完全精準，但狀態轉換必須落在合理範圍內。

| 行為 | 觸發／維持 | 恢復／例外 |
| --- | --- | --- |
| 護理師跟隨前方病患 | 約 2 公尺前開始減速；正常跟隨約 1 公尺。 | 小於約 0.8 公尺暫停；病患拉開至約 1.1–1.2 公尺後平順起步。 |
| 機器人離開護理站 | 指定巡房護理師或醫療車在出口約 2 公尺內才觸發出口安全點等待。 | 對方離開或距離超過約 2 公尺後恢復。遠處無關角色不得觸發。 |
| 機器人一般安全點 | 病患、點滴架、護理師或醫療車距離超過約 2 公尺後，才進行正常路徑探測。 | 若路徑仍受角色阻擋，安全點累積等待滿 2 秒後恢復原任務，可短時間穿越角色碰撞。 |
| 病患門側等待 | 病患身體抵達指定門側安全點，且點滴架不再占用門洞。 | 護理師、醫療車或機器人可沿門中心線進出；固定牆面與玻璃檢查仍有效。 |
| 無位移重派 | 實際位置連續 1.2 秒沒有變化。 | 只重建原本任務，不得改派到另一間病房或穿越房間側牆。 |

## 三、情境驗收矩陣

| ID | 情境與固定起點 | 必須看到的結果 | 不可接受結果 | 優先級 | 狀態 |
| --- | --- | --- | --- | --- | --- |
| T-01 | 護理師推醫療車離開護理站，前方病患正沿原路回病房 1。 | 護理師在接近前方約 2 公尺開始減速；病患維持原速與原路；護理師在約 1 公尺後跟隨。 | 到病房 1 門口才停、兩者融合、病患被迫改道、護理師左右閃避。 | P0 | 待回放 |
| T-02 | 護理師／病患與機器人迎面行走，但雙方各在固定靠右車道。 | 路徑不交疊時持續前進，不因單純的近距離數值停等。 | 兩方在不同車道仍互相倒退、停在中庭東北轉角、或被拉回中央線。 | P0 | 待回放 |
| T-03 | 病患從中庭東側自動門出來，目的地為病房 2。 | 先沿中庭外側與走廊右側線前進，再以短支線進入病房 2。 | 在東側門卡住、斜切病房 2 門、走到走廊中央、門口抖動。 | P0 | 待回放 |
| T-04 | 機器人剛離開護理站，指定巡房護理師／醫療車位於出口附近。 | 只有對方距離約 2 公尺內時，機器人在出口安全點穩定等待；對方離開後恢復。 | 5 公尺外就停、遠處其他護理師讓機器人持續等待、對方離開後不復原。 | P0 | 待回放 |
| T-05 | 機器人在走廊遇到病患、點滴架、護理師或醫療車。 | 先預判並退到安全點；對方超過約 2 公尺後恢復探測。若仍阻擋，安全點等待滿 2 秒後恢復原任務。 | 無限期停等、反覆退回同一點、因人物碰撞卡死、穿越牆面或玻璃。 | P0 | 待回放 |
| T-06 | 病患已在病房門側完成停等，身體與點滴架位於門側安全區。 | 護理師、醫療車與機器人可直接沿門中心線進出，忽略該病患與點滴架的角色碰撞。 | 仍停在門外、門口原地打轉、病患被推回門洞、機器人重新建立同一等待點。 | P0 | 待回放 |
| T-07 | 護理師在門側等待，兩名或三名同病房病患連續出房。 | 前一位病患先向前讓位，下一位接替門側等待點；隊列逐一消化並留下護理師／醫療車進房空間。 | 多名病患疊在同一點、前位病患不前進、後位病患無法出房、護理師永久等候。 | P0 | 待回放 |
| T-08 | 護理師在病房內準備離開，房內已有已進門病患。 | 護理師與醫療車沿原病房門中心線離房；尚未清門前不得判定下一間病房交接。 | 轉身穿牆、切往另一間病房、在房內原地轉圈、離房任務被錯誤重建。 | P0 | 待回放 |
| T-09 | 病患曾因護理師或機器人離開而停在病房外一段距離。 | 若連續 1.2 秒無實際位移，清除失效等待並從目前位置恢復原本回床任務。 | 病患永久停在門外、後續病患被堵住、重派後改走錯誤病房或穿牆。 | P0 | 待回放 |
| T-10 | 護理師在病患後方以不同速度跟隨、暫停、再起步。 | 腳步相位依實際位移變化；停步時腿部穩定，起步時平順增加，不左右抖動。 | 角色不動但腿持續擺動、護理師與醫療車前後融合、起步突然跳動。 | P1 | 待回放 |
| T-11 | 病患在門側讓機器人進病房，機器人位於門外另一側。 | 機器人抵達安全點後取得門中心通行，病患完成進房，機器人不再停在門外。 | 病患已讓位但機器人不進門、雙方門口抖動、病患進門後又走回門洞。 | P0 | 待回放 |
| T-12 | 同時出現病患、護理師／醫療車、機器人與另一名遠處病患。 | 只有實際路徑交疊的兩方進入等待；其他角色照原任務前進。 | 一個門口事件造成遠處多名病患同步停住，或等待原因轉移到無關角色。 | P0 | 待回放 |

## 四、每次回放應記錄的欄位

為了讓下一次修正能直接定位原因，每個失敗情境至少記錄：

| 欄位 | 內容 |
| --- | --- |
| 情境 ID | 例如 T-05、T-08。 |
| 角色與索引 | 病患、護理師、醫療車、機器人的識別。 |
| 目前狀態 | outbound、returning、door handoff、safety yield、waiting 等。 |
| 等待原因 | 哪一名角色、哪一個點滴架、哪一個門口或哪一個幾何檢查觸發。 |
| 觸發距離／時間 | 當下距離、等待累積時間、最後一次實際位移時間。 |
| 路點資訊 | 目前路點、下一路點、是否位於靠右車道或門洞。 |
| 結果 | 通過、卡死、融合、抖動、穿牆、錯誤重派或全域連鎖停等。 |

## 五、建議回放順序

先驗證會影響最多後續情境的基礎規則，再驗證門口複合情境：

1. T-02 固定靠右與不必要停等。
2. T-01 護理師／醫療車彈性跟隨。
3. T-04、T-05 機器人出口與安全點等待。
4. T-06、T-11 病患門側完成停等後的進出。
5. T-07 連續病患門口隊列。
6. T-08、T-09 護理師與病患的失效任務恢復。
7. T-03、T-10、T-12 路線、動作與多角色壓力情境。

只有在 P0 情境沒有出現卡死、全域連鎖停等、穿牆或持續融合後，才進入下一次正式發布前的建置與部署流程。
