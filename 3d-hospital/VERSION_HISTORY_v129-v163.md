# Medify 3D Hospital 版本紀錄：v129～v163

本文件記錄 Medify 3D Hospital 從 v129 至 v163 的功能新增、調整與修正。

- 對應備份：[Backup Medify 3D Hospital v163](https://github.com/agent863/medify/commit/2d215ab97bf32a510d584f4796b74f94dbc5a2d7)
- 網站版本範圍：v129～v163，共 35 個版本
- 主要範圍：病患動線與防卡、病患追蹤、手機操作、角色互動、環境音與音樂、手動停滯恢復

## 病患流程與導航

| 版本 | 調整／新增內容 |
|---|---|
| v129 | 維持病患持續入院；將街道人群納入避讓系統，路人會禮讓離院病患。 |
| v130 | 優化離院病患的街道行走：速度接近路人、同方向保持間距，迎面行人不再互相卡住。 |
| v131 | 新增叫號病患監控；任務遺失或停滯時，重新恢復原診間、醫師、護理師與路線。 |
| v132 | 移除隱藏候補病患；病患走到街道畫面外才回收，再從街道端產生新病患。 |
| v133 | 修復病患、診間護理師與醫師互相等待造成的流程死鎖。 |
| v134 | 一般人物路線不再使用座位中心與座位區內的備用路點。 |
| v135 | 將候診座位前排及上方區域設為一般人物不可穿越；只有座位使用者可以進出。 |
| v136 | 人群避讓導致停滯時，先前往安全空位，再恢復原本的看診、掃描、領藥或離院任務。 |

## 病患追蹤、手機操作與角色互動

| 版本 | 調整／新增內容 |
|---|---|
| v137 | 初次加入病患追蹤標記、狀態資訊與醫護姓名；調整診間護理師坐下動作。 |
| v138 | 因 v137 問題回復至 v136，因此 v137 的內容暫時撤回。 |
| v139 | 重新加入病患追蹤：病患上方顯示旋轉紅色倒金字塔、病患編號及即時狀態；加入醫護姓名與 QR 說明。 |
| v140 | 放大並提高病患標記；補充候診、診間 QR、看診後資訊與藥袋 QR 等詳細狀態文字。 |
| v141 | 手機／平板加入雙指平移畫面，保留單指旋轉與雙指縮放。 |
| v142 | 加入雙指旋轉；小鳥可點擊並顯示「祝你有美好的一天，啾～」。 |
| v143 | 修正雙指旋轉方向；手機版顯示右上角角色圖例；護理師數量更新為 9。 |
| v144 | 角色圖例加入「藥師 × 2」，並與護理師數量分開計算。 |
| v145 | 擴大小鳥的隱形點擊範圍，提高手機上的點擊成功率。 |
| v146 | 修復電腦版小鳥點擊；手機追蹤病患時，鏡頭會讓病患持續維持在畫面中央。 |
| v147 | 加大候診座位前排的阻擋範圍，特別針對左下角座位區；找不到安全路線時不再直接穿過座位。 |
| v148 | 醫師只有在候診、坐在診間且未接待病患時才會向鏡頭打招呼，避免中斷看診。 |
| v149 | 入院病患改從街道尾端進場，完整走過人行道後才抵達醫院入口。 |

## 醫院環境音、音樂與叫號音

| 版本 | 調整／新增內容 |
|---|---|
| v150 | 加入醫院環境音及聲音開關，最初為合成的空調與遠處人聲。 |
| v151 | 增加遠處人聲層次，讓候診區更有背景交談感。 |
| v152 | 加入低音量背景音樂；一般提示音改為只在診間叫號時播放；提高環境人聲。 |
| v153 | 將空調聲音降低一半。 |
| v154 | 重製環境音，加入較具空間感的模糊交談與反射，減少沉重白噪音感；同時提高叫號音。 |
| v155 | 移除合成環境音，改用第一次提供的醫院候診室錄音。 |
| v156 | 環境音量降低 50%。 |
| v157 | 環境音量再降低 50%。 |
| v158 | 改用剪輯後的醫院環境音；音量再降低 20%；叫號音提高 30%。 |
| v161 | 背景音樂改成「StudioKolomna - 30 sec version.mp3」，維持原本網頁音樂音量。 |

## 叫號防卡與手動恢復

| 版本 | 調整／新增內容 |
|---|---|
| v159 | 叫號病患即使遇到臨時人群阻礙，也會保留前往原診間的目標與檢查點。 |
| v160 | 同時叫號的病患加入固定通行優先順序；相遇時其中一人會禮讓，避免兩人互卡。 |
| v162 | 新增「點擊停滯人物重新前進」：清除暫停、避讓與繞路狀態，並恢復當前任務。 |
| v163 | 將點擊恢復改為兩階段：先尋找附近可通行空位，移動到空位後再繼續原任務。 |

## v163 當時的已知狀況

v163 已加入「移步至可通行空位」機制，但當時仍可能出現角色只校正方向、沒有真正踏出第一步的情況；這個第一步鎖定問題後續於 v164 進一步修正。
